# budget-tracker
Project Description

This is a full-stack Personal Budget Tracker web application developed using the MERN stack. It allows users to manage their income and expenses, track financial activities, and view real-time summaries with charts.

Project Objective 
  -To help users track daily income and expenses 
  -To provide a clear financial overview 
  -To store and manage transaction data efficiently

Technologies Used

MongoDB – Database
Express.js – Backend framework
React.js – Frontend library
Node.js – Runtime environment
Axios – API communication
Chart.js – Data visualization

Installation & Setup

  Clone Repository git clone https://github.com/csaniya/budget-tracker.git
  cd budget-tracker

Backend Setup 
  cd server 
  npm install 
  node server.js

Frontend Setup 
  cd client 
  npm install 
  npm start

Run Application 
  Frontend: http://localhost:3000 
  Backend: http://localhost:5000

Features 
  -Add income and expense transactions 
  -Delete transactions 
  -View total balance, income, and expenses 
  -Data stored in MongoDB 
  -Real-time updates 
  -Interactive chart visualization

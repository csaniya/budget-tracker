Project Description

This is a full-stack Personal Budget Tracker web application developed using the MERN stack.
It allows users to manage their income and expenses, track financial activities, and view real-time summaries with charts.

Project Objective
  -To help users track daily income and expenses
  -To provide a clear financial overview
  -To store and manage transaction data efficiently

Technologies Used
1. MongoDB – Database
2. Express.js – Backend framework
3. React.js – Frontend library
4. Node.js – Runtime environment
5. Axios – API communication
6. Chart.js – Data visualization

Installation & Setup
1. Clone Repository
  git clone https://github.com/your-username/budget-tracker.git
  cd budget-tracker

2. Backend Setup
  cd server
  npm install
  node server.js

4. Frontend Setup
  cd client
  npm install
  npm start

5. Run Application
  Frontend: http://localhost:3000
  Backend: http://localhost:5000

Features
  -Add income and expense transactions
  -Delete transactions
  -View total balance, income, and expenses
  -Data stored in MongoDB
  -Real-time updates
  -Interactive chart visualization
